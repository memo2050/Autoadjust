How to connect real data sources
  1. Deploy the Spark app on a server (for example Vercel) with a Supabase database. In Supabase run supabase/003_soc.sql.
  2. Set these server environment variables: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, ANTHROPIC_API_KEY, SOC_ADMIN_TOKEN and SOC_INGEST_TOKEN (each token: 32+ random characters).
  3. Open this workspace on that deployment and paste SOC_ADMIN_TOKEN when asked.
  4. On a Windows computer you own or are authorized to monitor, run collector/windows/Send-SecurityEvents.ps1 with your site URL and SOC_INGEST_TOKEN. It sends real Security, System and Defender events (read-only).
  5. In Greenbone/OpenVAS download a report as XML or CSV and import it with the button in the Vulnerability panel. You will be asked to confirm you are authorized to test those hosts.
  6. Full steps, tests and limits: docs/SOC.md.
